# SUNDARBAN-DARK-TRAILS
🌿 Sundarban Dark-Trails — Web Application
A responsive, high-performance web application designed for eco-tourism operators, luxury houseboat charters, and wildlife safari bookings in the Sundarbans Mangrove Delta (West Bengal, India).

Built with semantic HTML5, modern CSS3 variables, and vanilla JavaScript (ES6+). Zero external framework dependencies.

✨ Features & Capabilities
Interactive Availability Bar: Hero section search with automated min="today" date validation to prevent booking in the past.
Dynamic Package Category Filter: Real-time filtering across Day Safaris, Overnight Escapes, and VIP/Specialist packages without page reloads.
5 Comprehensive Tour Packages: Covers budget day cruises, flagship eco-cottage getaways, deep-core tiger trails, private luxury houseboat charters, and photography safaris.
Real-Time Cost Estimator:
Live slider for traveler count (1–15 persons).
Transport choices: Self-arrival at Godkhali, Kolkata shared AC bus (+₹1,200/person), or private sedan (+₹4,800 flat).
Add-ons: Local seafood feast (+₹500/person) and professional telephoto lens camera permit (+₹1,000 flat).
Direct WhatsApp Booking Engine: Modal form validates lead guest details and opens a pre-formatted WhatsApp reservation message addressed to your booking desk.
Floating Quick-Contact Button: Direct WhatsApp contact button anchored for mobile & desktop conversions.
Accessible Accordion: Travel guidelines and forest permit FAQs with smooth height animations.
Lightweight & SEO-Ready: Includes Open Graph meta tags, semantic hierarchy, and Google Fonts
